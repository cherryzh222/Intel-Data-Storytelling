# Intel Data Storytelling & Visualization

Marketing analytics project by Cherry. Static site: no build step, no libraries. Six sections that mirror the project brief: one intro and five insights, each with a chart, a headline and a short narrative.

```
intel-data-storytelling/
├── index.html      the six sections and the data table
├── styles.css      design
└── script.js       the 8 charts (data is at the top of the file)
```

## Preview locally

Open `index.html` in a browser.

## Publish on GitHub Pages

1. Create a public repository and upload the three files.
2. Settings → Pages → Deploy from a branch → `main` / `(root)` → Save.
3. The site is live at `https://<username>.github.io/<repository>/`.

Independent student project using Intel's reported 2019–2025 figures as provided in the project brief. Not affiliated with or endorsed by Intel.
